# رفيق | مساعدك الدراسي

مساعد دراسي عربي للصف الثالث الثانوي (المنهج السوداني، المسار العلمي). يختار الطالب مادته ودرسه، فيشرحه رفيق ويعلّمه خطوة بخطوة ويختبره ويصحح إجاباته، وينشئ الملخصات والبطاقات والخرائط من كتبه، مع استشهاد بصفحة كل معلومة. React + TypeScript + Vite على GitHub Pages، ووسيط Cloudflare Worker للذكاء الاصطناعي.

## ما يفعله الطالب

- **الرئيسية:** المادة ← الدرس ← اشرح لي، أو علّمني خطوة بخطوة، أو لخّص، أو اختبرني.
- **مساحة الدراسة:** شريط «أدرس الآن» للدرس الحالي، ومستوى الشرح (مبسط جداً، عادي، متعمق)، ومحادثة تفهم الطلبات الطبيعية: شرح الدرس على أجزاء، وسؤال فهم بعد كل فكرة يُصحَّح، وأمثلة، وخطوات حل، وجداول مقارنة، وأهم ما يُحفظ، والأخطاء الشائعة. ما يضيفه رفيق من خارج الكتاب يظهر في إطار مستقل.
- **القارئ:** فقرات كل صفحة مع أزرار: اشرحها ببساطة، مفصل، خطوة بخطوة، مثال، المصطلحات، سؤال تدريبي.
- **المراجعة:** ملخصات قابلة للتعديل (تفصيلي، مختصر، ليلة الامتحان، التعريفات، القوانين، نقاط الحفظ، أسئلة متوقعة للتدريب)، واختبارات بسبعة أنواع أسئلة وتصحيح ذكي للإجابات المكتوبة، وبطاقات بتكرار متباعد وإضافة يدوية، وخرائط ذهنية، ومقارنات.
- **التقدم:** الدروس المدروسة، ونتائج الاختبارات، والموضوعات التي أخطأ فيها الطالب مع زر مراجعتها. لكل طالب بياناته المنفصلة.

دون ذكاء اصطناعي تعمل القراءة والبحث والمراجعة، ويعرض رفيق نص الدرس من الكتاب مع سبب واضح.

- الموقع: https://do99no.github.io/rafeeq-study/
- كل تعديل يُرفع إلى `main` يُنشر تلقائياً خلال دقيقة تقريباً (GitHub Actions).

## التشغيل محلياً

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # فحص الأنواع والبناء إلى dist
```

المكتبة والقارئ والبحث النصي والمراجعة تعمل دون أي مفتاح.

## الكتب

الكتب منشورة **مشفرة** (AES-256-GCM) في `public/library`. لا يفتحها إلا من معه رمز المكتبة، ويكتبه الطالب مرة واحدة في صفحة المكتبة. الرمز محفوظ محلياً في `books-work/library-code.txt` ولا يُرفع إلى Git.

أصول الكتب وكل نتائج المعالجة محلية ومستثناة من Git: `books/` و`books-alt/` و`books-work/`.

### إضافة كتاب أو إعادة معالجته

```bash
node scripts/extract-books.mjs          # طبقة النص لكل PDF
node scripts/ocr-books.mjs run          # التعرف الضوئي، يكمل الصفحات الناقصة فقط
node scripts/pack-books.mjs             # الفهرس + التشفير إلى public/library
```

- لكتاب جديد: ضعه في `books/` أو `books-alt/`، وأضف عنوانه ومادته في `books-work/catalog.json` بمعرّفه (يطبعه `extract-books`).
- **قوائم الدروس** في `books-work/toc/<المعرّف>.json`: وحدات (level 1) ودروس (level 2) برقم صفحة PDF، وكل بند متحقق منه على صفحته. `node scripts/toc-dump.mjs` يكتب لكل كتاب صفحات الفهرس وبدايات الصفحات للمساعدة في بنائها.
- ملف PDF المشفر لا يُعاد تشفيره عند تغيّر الدروس أو المقاطع: يُنشر ملف فهرس صغير (idx) وتحدّث الأجهزة كتبها تلقائياً عند فتح التطبيق.
- لإعادة OCR صفحات محددة: احذف ملفاتها من `books-work/ocr/<المعرّف>/` ثم شغّل `run`.
- بعدها ارفع التعديل إلى `main`. ما لم يتغير من الكتب لا يُعاد تشفيره.

يمكن أيضاً إضافة PDF مباشرة من صفحة المكتبة، فيُعالَج داخل المتصفح.

## تفعيل الذكاء الاصطناعي

### محلياً
1. انسخ `worker/.dev.vars.example` إلى `worker/.dev.vars`.
2. ضع `ACCESS_CODE` (رمز طويل من اختيارك) ومفتاح مزود واحد على الأقل.
3. شغّل `npm run worker` في نافذة أخرى.
4. في الإعدادات اكتب رمز الوصول ثم «حفظ وفحص».

### للموقع المنشور (بموافقة صاحب المشروع)
1. من مجلد `worker`: سجّل الدخول بـ `npx wrangler login`.
2. اضبط `ALLOWED_ORIGINS = "https://do99no.github.io"` في `wrangler.toml`.
3. أضف الأسرار: `npx wrangler secret put ACCESS_CODE` ثم `GEMINI_API_KEY` وغيره.
4. انشر: `npx wrangler deploy`.
5. ضع رابط الوسيط في متغير المستودع `WORKER_URL` (Settings ← Variables)، أو اكتبه في الإعدادات داخل الموقع.

لا توضع المفاتيح في الواجهة ولا في Git. `worker/.dev.vars` مستثنى.

## البنية

- `src/services/books`: استخراج PDF والتعرف الضوئي والمقاطع والحالة ومكتبة المنهج المشفرة.
- `src/services/rag`: البحث النصي (BM25 مع تحمّل أخطاء OCR) والدلالي والهجين.
- `src/services/ai`: مدير المزودين والتناوب. المزودون في `worker/providers.mjs`.
- `src/services/study`: الإجابة والملخصات والاختبارات والبطاقات والخرائط والمقارنة.
- `scripts`: معالجة الكتب على الكمبيوتر.
