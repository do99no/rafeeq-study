## معيار «الدرس جاهز»

لا يكفي نجاح التوليد. الدرس جاهز (`checked`) حين:

- الشرح خطوتان على الأقل، ولكل خطوة سؤال فهم (أو معظمها).
- الملخص الشامل والمختصر وليلة الامتحان، ودليل الدراسة، ومصطلح أو قانون على الأقل، ونقطتان مهمتان، وخطأ شائع، وخريطة ذهنية بفرعين.
- 3 أسئلة وأجوبة، 5 بطاقات، 3 أسئلة لكل مستوى (سهل، متوسط، صعب)، 3 تمارين في ورقة العمل.
- كل رقم استشهاد يقابله مقطع محفوظ، وكل مقطع في صفحات الدرس، وكل بند مرتبط بمصدر.
- إجابة الاختيار بين خياراته، وصح وخطأ صالحة.

العلامات:

- `flagged`: بنود عليها «تحتاج مراجعة» (حل مستقل مختلف، أو مسألة علمية لم يُتحقق منها آلياً). تظهر للطالب بالعلامة نفسها.
- `verified`: أسئلة الرياضيات حُلّت حلاً مستقلاً (طلب منفصل لا يرى الإجابات) وقورنت النتائج برمجياً. التطابق فحص إضافي وليس برهاناً.
- «راجعه المسؤول»: مراجعة بشرية من لوحة الجاهزية.

## الأخطاء المعروفة

- النموذج الرئيسي في Gemini (gemini-3.8-flash) يعيد 503/524 كثيراً؛ يتحول الخادم إلى النموذج المجاني التالي ويترك المزدحم 3 دقائق.
- بعض الدروس تفشل في التجهيز؛ السبب يُسجَّل الآن في سجل الصفحة، ويُعاد الدرس في الجولة التالية.

## الأوامر

- فحص الأنواع والبناء: `npm run build`
- خادم محلي: `npm run worker` (يقرأ `worker/.dev.vars` غير المرفوع)
- واجهة محلية: `npm run dev`
